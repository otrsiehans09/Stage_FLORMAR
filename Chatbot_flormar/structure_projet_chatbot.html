Cliquez sur un fichier pour voir son rôle détaillé
chatbot-shopify/— racine du projet
├── .env SECRET — clés API (ne jamais commiter)
Contient toutes les clés secrètes : GROQ_API_KEY, SHOPIFY_ACCESS_TOKEN, etc. Ce fichier ne doit JAMAIS être envoyé sur GitHub. Ajoutez-le à .gitignore dès le début.
├── .gitignore config — fichiers à exclure de git
Liste les fichiers que git ne doit pas suivre. Contient au minimum : .env, __pycache__/, *.pyc, venv/
├── requirements.txt deps — dépendances Python
Liste toutes les librairies Python nécessaires. Générée avec pip freeze. Permet de réinstaller tout l'environnement avec : pip install -r requirements.txt
├── app.py Python — point d'entrée principal
Fichier principal du backend FastAPI. Définit les routes HTTP (ex: POST /chat), démarre le serveur, orchestre les appels entre les modules. C'est le "chef d'orchestre" de tout le projet.
├── config.py Python — variables de config centralisées
Lit le fichier .env et expose les variables comme GROQ_API_KEY, SHOPIFY_URL, etc. Centralise toute la configuration pour ne pas la répéter dans chaque fichier. C'est ici que vous changez d'API en 2 lignes.
├── system_prompt.py Python — system prompt du chatbot
Contient le system prompt complet défini à l'Étape 2. Exposé comme une variable Python réutilisable. Permet de modifier le comportement du chatbot sans toucher au reste du code.
├── groq_client.py Python — appels à l'API Groq
Gère toute la communication avec l'API Groq (Llama 3.1). Prend en entrée : le system prompt + l'historique + le message du client. Retourne la réponse du modèle. Facilement remplaçable par un autre client (Gemini, Claude...).
├── shopify_client.py Python — connexion à l'API Shopify
Communique avec l'API Shopify pour récupérer les produits, variantes, prix et stocks. Formate les données en texte clair pour les injecter dans le contexte du chatbot.
├── session_manager.py Python — mémoire des conversations
Maintient l'historique de chaque conversation en cours (par session_id). Garde en mémoire les derniers échanges pour que le chatbot comprenne le contexte. Réinitialisé à chaque nouvelle session.
└── shopify-theme/ — fichiers pour le thème Shopify
Dossier contenant les fichiers à intégrer dans votre thème Shopify. Ces fichiers s'ajoutent à votre boutique via l'éditeur de thème Shopify.
├── chatbot-widget.js JS — widget visible dans la boutique
Le widget de chat affiché sur votre boutique Shopify. Gère l'interface utilisateur (bulle de chat, fenêtre, messages) et envoie les messages au backend Python via fetch(). S'intègre dans le thème via un snippet Liquid.
└── chatbot-snippet.liquid Liquid — inclusion dans le thème
Fichier Liquid qui charge le widget JS dans le thème Shopify. S'ajoute dans le fichier theme.liquid pour que le chatbot apparaisse sur toutes les pages de la boutique.
